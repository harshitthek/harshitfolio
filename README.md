# HARSHIT.EXE — Next-Generation Cinematic Cyberpunk Multiverse Portfolio

A cinematic, interactive multiverse developer portfolio experience for **Harshit Sharma** (AI & ML Engineering at USAR, GGSIPU), engineered with React 18, Vite, Procedural Web Audio Synthesizer, Speech Synthesis AI Voiceover, and an AI-driven Neural Synapse Particle Canvas.

🌐 **Live Local Dev Server**: `http://localhost:5173`

## ⚡ 5-Screen Cinematic Flow & Features

1. **🎬 Video Intro Screen (`s-video`)**
   - Cinematic background video with audio unmute interaction overlay (`▶ Tap Into the Experience`)
   - Interactive CRT scanlines & corner brackets with instant `SKIP ›` control.

2. **⏳ Holographic Database Loading (`s-intermediate`)**
   - 3D Grid Pan animation (`@keyframes gridPan`) with radial vignette
   - Glitch slicing pulsing glyph (`LOADING`) and counter-rotating cyber rings (`@keyframes spin`)
   - Audio voiceover: *"Loading mission database. Stand by."*

3. **📜 Classified Mission Briefing (`s-mission`)**
   - Classified Agent Harshit Sharma dossier briefing (USAR, GGSIPU, New Delhi)
   - Audio narration: *"Incoming classified mission. Welcome to Harshit Sharma's portfolio..."*
   - Interactive slide-fill button with corner brackets (`▶ ACCEPT MISSION & LAUNCH HUB`)

4. **🌌 Multiverse Destination Deck (`s-cards`)**
   - **8 Flagship Engineering Portals**:
     1. **`PORT_01 / YGGDRASIL`**: **Yggdrasil Bot** — Multi-Agent Discord AI & Knowledge Tree Engine
     2. **`PORT_02 / RESILIENT`**: **Resilient** — Autonomous AI Coding Agent Benchmark & Sandbox Pipeline
     3. **`PORT_03 / ML_VALUATION`**: **Used Bike Price Predictor** — RandomForest ML Valuation Engine (98.4% R²)
     4. **`PORT_04 / CARBON_AI`**: **Carbon Guardian AI** — Cloud Compute Telemetry & Emissions Optimization
     5. **`PORT_05 / 3D_COSMIC`**: **3D Cosmic WebGL Portfolio** — 6-Mode Three.js Physics Engines & Shaders
     6. **`PORT_06 / STARTPAGE`**: **Customizable Browser Startpage** — High-Performance Dashboard & Live Web APIs
     7. **`PORT_07 / SYSTEMS`**: **Production Systems & Webhooks** — HMAC-SHA256 Signature Verifier & PostgreSQL Schema
     8. **`PORT_08 / SHELL`**: **Harshit's Cyber Shell Console** — Embedded Terminal with Interactive AI Assistant
   - Category filter tabs (`ALL`, `AI AGENTS & DISCORD`, `ML & PREDICTIONS`, `3D WEBGL`, `SYSTEMS`)
   - Instant live search bar
   - Dual actions per card: `[👁️ INTEL]` for in-app deep-dive modals, and `[→ DEPLOY & LAUNCH]` for simulated terminal hacking sequence

5. **💻 Simulated Terminal Hacking Deployment (`s-loading`)**
   - Simulated terminal execution logs (pinging servers, authenticating SSH RSA key, fetching assets, compiling bundle, deploying)
   - Glowing progress bar with moving spark indicator (`.progress-glow`)
   - Confetti celebration chime upon completion, redirecting to destination.
